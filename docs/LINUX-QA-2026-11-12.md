## Confirmed defects and fixes

**Network relocation:** the old MQTT socket remained apparently connected to the previous Wi-Fi address. The zero response timeout allowed that stale state to persist. Linux now uses a 30-second keepalive and 15-second ping-response deadline, including when rebuilding the client. Reconnection republishes presence.

**Configuration revision collision:** restored preferences held revisions from an older registration. A new authoritative player registration could have a lower or equal revision, causing rotation commands to be ignored. Revisions now persist with an environment/player-registration scope. Changing that authoritative scope resets revision comparison; stale commands within the same registration are still rejected.
