# Byte internal-storage regression test — 2026-11-02

## Environment

- Ubuntu 24.04.4 LTS, x86_64, X11, 1920x1080 at 60 Hz.
- Persistent root on internal eMMC `/dev/mmcblk0p2`; EFI on p3. USB removed.
- 3.7 GB RAM and 3.6 GB disk swap.
- Lab screen only: `MPM-LAB-LNX-01 | Azulle Internal v25 Test`, code `144c48`.

## Reproduced failures in v25

- Image loaded and video advanced without a playback error.
- Native SIGSEGV when the web clock initialized, followed by service restart.
- Approximately 2.3 GB RAM available and no swap usage at failure.
- The saved core faults in Flutter's external-texture callback: its populate
  operation returns false with a null GError, then `error->message` is read.
- `FrameStore::Snapshot` returned false before the first CEF paint, leaving
  the texture callback without a frame or an error. The crash reproduces on
  persistent storage, independently of the previous live-USB memory pressure.
- CEF initialization also opened a GNOME keyring-creation prompt, blocking
  unattended startup until cancelled.

## Fix

- Start every browser texture with a valid transparent 1x1 RGBA pixel.
- Preserve the placeholder through repeated requests and rejected paints.
- Set GError on the defensive failure path instead of silently returning false.
- In explicit kiosk sessions only, use Chromium's basic store to avoid an
  interactive keyring dependency. Browser profile files depend on account file
  permissions rather than OS-keyring encryption; do not save personal browser
  passwords in the kiosk profile. The service uses umask 0077.

## Validation

- Local ASan/UBSan frame-store regression, including pre-paint snapshots,
  concurrent producer/consumer updates, retained buffers and destruction: pass.
- Hardware acceptance is pending the new CI artifact. Source checks alone do
  not establish runtime stability or overnight reliability.
