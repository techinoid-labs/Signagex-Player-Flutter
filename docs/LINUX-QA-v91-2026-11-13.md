## Hardware boot recovery

The correct Ubuntu root is `/dev/nvme0n1p2` on the Kingston drive. The older OS
is on the separate built-in eMMC. Linux BootOrder changes, and even clearing
the eMMC entry's active flag, did not fix automatic selection.

The operator's BIOS photograph showed **FIXED BOOT ORDER Priorities**:
`Boot Option #1 = Hard Disk: UEFI OS`, `Boot Option #2 = NVMe: ubuntu (KINGSTON)`.
The operator changed **Boot Option #1** to Kingston/Ubuntu in BIOS and saved
with **F4**. Subsequent SSH checks confirmed `BootCurrent=0007`, Ubuntu first
in BootOrder and root on Kingston. A further normal reboot of v87 passed
without F7. The final v91 reboot also passed: fresh v91 health matched PID 1207,
zero automatic restarts, root on Kingston, Ubuntu first and portrait retained.
This establishes normal reboot acceptance, not electrical power-loss testing.
